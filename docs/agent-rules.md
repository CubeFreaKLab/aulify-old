# Repository Rules

- Do not implement product features until the relevant app, service, and contract decisions are approved.
- Do not create real pages before route ownership and layouts are defined.
- Do not create backend business endpoints before API contracts are documented.
- Do not connect Firebase before backend access patterns are implemented.
- Do not recreate the Aulify logo with text. Use the official SVG asset when it is added to `assets/brand`.
- Keep comments rare and limited to non-obvious business decisions.
- Use Inter as the only typography.
- Use only official design tokens from `docs/design-system.md`.
- Do not add private planning files to the repository.
