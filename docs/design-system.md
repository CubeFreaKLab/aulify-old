# Design System

Aulify uses a calm, educational interface. The platform is not game-first.

## Typography

- Font family: Inter
- No secondary typefaces are planned.

## Color Tokens

| Token | Value |
| --- | --- |
| Primary green | `#049A4E` |
| Light green | `#B8FAC6` |
| Off-white | `#FAFAF8` |
| Light gray | `#ECECE7` |
| Dark gray | `#60615A` |
| Black | `#0F0F0F` |
| White | `#FFFFFF` |

Do not invent additional colors. Any new token must be approved and documented here first.

## Brand Assets

The Aulify logo must be used later as an SVG asset in `assets/brand`. It should not be recreated with text in product UI.
