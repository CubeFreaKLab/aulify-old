# GraphQL Schema

Aulify uses GraphQL for dashboard and insight read models.

## Planned Query Areas

- Current user dashboard
- Course progress summaries
- Task overview
- Activity results summaries
- Insight summaries

GraphQL should not own write actions for Aulify 1.0. Mutating workflows should use REST endpoints.

No schema is implemented yet. Types and resolvers should be added after service ownership and read models are finalized.
