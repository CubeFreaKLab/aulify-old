# Routes and Screens

This document records planned surfaces only. It does not define page implementation.

## Public Domains

- `aulify.org`: landing app
- `app.aulify.org`: authenticated web app
- `api.aulify.org`: API gateway

## Apps

### Landing

Planned for public marketing and product information.

### Web

Planned for authenticated course, note, task, activity, and insight workflows.

### API Gateway

Planned as the public backend entry point for REST actions and GraphQL dashboard queries.

## Screens

Specific screens are intentionally not created yet. Route files should be added only when layouts, access rules, and data contracts are ready.
